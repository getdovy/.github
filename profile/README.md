Newer and missing software for Debian stable, on top of apt. Not part of Debian.

| Project | |
|---|---|
| [dovy](https://github.com/getdovy/dovy) | Installs software Debian does not ship, as packages built locally |
| [dovy-catalog](https://github.com/getdovy/dovy-catalog) | Signed recipes for dovy |
| [dovy-kernel](https://github.com/getdovy/dovy-kernel) | Debian's backports kernel, tweaked for performance |
